Наш проект представляет собой инновационное решение для строительной отрасли — нейросеть, специализирующуюся на обработке изображений труб и точном подсчете их количества. Эта технология существенно оптимизирует рабочий процесс, избавляя строителей от необходимости вручную перебирать  трубы. Автоматизация данной задачи значительно сокращает временные затраты и повышает общую эффективность строительных операций. папка Unet_model лежит на яндекс диск по ссылке https://disk.yandex.ru/d/RtW8PTJy42cNNQ
